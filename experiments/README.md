# Future experiment extension

The old drafter's academic studies live on archive/hierarchical-drafter. This tree
contains reusable native implementation and six implementation workflows only.

A future `experiments/<study_id>/` may contain a README, selected native config
paths, a declaration of intended comparisons, and references to immutable native
run/manifest hashes. Model, loss, data, checkpoint, and inference code must remain
in `src/ncm_lab`. Store generated runs under ignored `runs/`, not copied source.
Do not select arbitrary historical latest runs or relabel fixtures as research.
No study designs, baselines, sweeps, venue-specific registries, or hypotheses are
instantiated by this migration.
