# Setup acceptance and remaining evidence

The original GPL license is unchanged. Shared implementation responsibilities live
in ncm_lab contracts/data/models/decoding/training/evaluation/business/runtime/
experiments/reporting. CPU install, CLI help and offline planning are reproducible.
The eleven core experiment directories have protocols, configs, analysis entries and
pending result indexes. The root README links every experiment.

Architecture correctness is checked by nested partitions, actual stage lengths,
strict per-anchor feature masks, direct flat upstream parity, trainable expansion
and zero-gate behavior, frozen-target gradients and cache rollback. Small original
licensed financial train samples validate official gold/scoring and prompt separation.
No generated business gold or fake empirical table is present.

Budgets bound steps, time, source passes, supervised positions, storage, downloads,
and aggregate phase reservations. Runs retain resolved inputs, append-only events,
failure accounting, artifact digests, counters and final checkpoint identifiers.
Planning never launches training/downloads. Reporting and exports use selected
study manifests; fixture and changed/missing evidence is rejected. AI assistance and
human contribution assignments are tracked separately.

Unfinished research prerequisites are explicit in implementation_status.md: GPU /
released-weight parity, optimized backend integration and baseline reproduction,
full evaluator/data audits, genuine code isolation, real end-to-end financial serving
and operating-frontier measurements, repeated-seed learning/evaluation, and human
owners/reviewers. These cannot be established by a folder tree or CPU fixture run.
The setup implements the feasible local paths and prevents the missing evidence
from appearing as research findings. Native NCM conversion remains future work.
